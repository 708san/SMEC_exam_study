# 診断士 Study Lab｜2027–2028
中小企業診断士の一次7科目・二次4事例の学習を一元管理する非公式の独自学習アプリ。GitHub Pages上で稼働し、個人データは端末内に保存する。現在は開発初期版であり、合格水準・網羅性は未検証。

## 目的
- 初学者が原理から理解できる独自教科書、図解、計算過程、具体例。
- 基礎・応用・本試験形式の演習と全選択肢の解説。
- 一次・二次、複数年度の計画、正式な科目合格・免除と学力の分離。
- 教材網羅率、読了、演習挑戦、正答、間隔を空けた再演習、模試を別指標として記録。
- 教材の追加・修正で履歴を失わない安定IDと版管理。端末間はJSONバックアップで移行。
- 教材の未実装・未監査を明示。問題数や読了だけで合格水準と判定しない。

## 現在の実装状況（2026-11-28）
- 暫定カリキュラム169論点。独自教材73単元（497節）、独自択一335問。経済17/17、財務29/29、企業経営26/26、運営1/22、法務0/16、情報0/14、中小企業経営・政策0/17。二次の体系的解説0/28、別途独自ミニケース4事例12設問。
- 2026年度一次7科目の公式問題への導線・227解答欄・公式配点による採点と途中保存。過年度や二次公式過去問の全件解説は未実装。
- 経済・財務・企業経営理論は公式案内の45項目群との対応表を実装。ただし細目の深さ・過去問対応・内容の独立監査は未完了。
- 企業経営理論は18単元を新規追加し、7単元を再改訂。147問の正解位置を分散し、概念図4種類と価格戦略の数値操作教材を追加。労働法の2025・2026年改正と2027年適用予定の制度は施行時点を区別して記載。
- 正答・読了・間隔を空けた再正答と正式合格・免除を区別。免除の申請中と確認済みを年度別に記録。確認済みのみ今期の推奨対象から除く。
- 自動検査は `node tests/smoke.mjs`、ブラウザ検査はGitHub Actionsの Browser quality checks（Playwright / Chromium、Ubuntu 24.04固定）。実機Safariと公開環境は別途確認。
- [品質評価と完成条件](docs/quality-report.md)

## 開発段階
1. 学習管理基盤、カリキュラムの暫定索引、保存・復元。
2. 公式細目と公開過去問の全件索引化、旧教材との照合。
3. 独自教科書・演習の順次追加。年度依存知識は適用年と根拠を記録。
4. 過去問・模試と二次答案演習、公式基準との照合。
5. 内容・範囲・計算・操作・保存・スマホの独立監査。
