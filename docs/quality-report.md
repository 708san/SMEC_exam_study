## 完成判定のゲート
以下が満たされるまで完成と宣言しない。
1. **出題範囲**：一次全科目・二次4事例を公式案内の細目と紐付け、対応漏れ・過剰な分類・重複を監査。出題実績のない論点も除外しない。
2. **教材**：全細目で原理・定義・前提・例・図表（適切な場合）・計算手順・適用限界・典型誤解を説明。旧保有教材を全件照合し、不足論点を補う。独立内容監査で重大誤りなし。
3. **年度対応**：法令・会計基準・統計・政策・白書を対象試験年度の基準日に照合し、原典・適用日・例外を記録。2027/28年度は公式発表後に再監査。
4. **一次演習**：公式公開過去問を年度・科目・論点に対応付け、正答・配点・訂正を確認。本試験相当の独自模試・応用問題と全選択肢解説、弱点診断を実装。
5. **二次演習**：体系的解説と本試験相当の長さ・構成を持つ演習、公式出題趣旨の照合、複数の妥当な答案と採点観点、時間管理と再答案。自己採点は公式合否と区別。
6. **操作・保存**：全画面の実ブラウザ回帰検査、iPhone Safari実機、公開環境、オフライン更新、バックアップ復元、旧記録維持、異常系、アクセシビリティの確認。
7. **学習妥当性**：初学者が外部説明なしで理解可能か、未見の本試験級問題に対応できるか、実際の学習による不足検出と再改訂を行う。合格そのものは保証しない。
