# 学習管理と教材品質仕様 v0.1

## 指標を混同しない
- 教材作成率：暫定論点に登録された教材数 / 暫定論点数。公式範囲網羅率ではない。
- 読了：現行改訂番号の教材を読了操作した論点数 / 暫定論点数。未作成論点は読了できない。
- 挑戦率：異なる問題IDの挑戦数 / 登録問題数。繰り返しで水増ししない。
- 通算正答率：全解答の正答 / 解答数。未回答は未測定。
- 定着：3日以上離れた正答2回かつ最新正答（暫定基準）。
- 過去問・模試：実施日、科目、試験名、100点換算値、種別を保存。手入力値であり公式判定ではない。
- 正式結果：科目合格年、一次・二次合格年。学習上の到達とは独立。免除申請の実施状況は今後追加。
- 学習時間：科目・日・分。直近7日と目標を比較。自動計測は今後追加。

## 優先する次の実装
1. 公式出題内容を項目ID・原典ページと対応させ、過去問を年度・科目・設問単位で索引化。未照合を可視化。
2. 暫定論点の下に細目を追加する。既存IDを再利用せず、親子関係と分割前IDを保持。学習記録を誤って完了扱いしない。
3. 問題改訂管理（旧版の正答履歴を新しい問題の習熟度に混ぜない）、同日反復で復習間隔を延ばさない。
4. 年度別受験計画、試験日までの残日数、科目ごとの必要時間・今週のタスク、進捗の遅れに応じた再計画。
5. 過去問の正答・配点照合と模試セッション、本番形式・未回答・時間計測・合格基準の判定。年度別免除設定、得点推移。
6. 二次事例の答案・文字数・制限時間・根拠・自己採点・再答案。公式出題趣旨と独自評価基準を区別。
7. 学習履歴の編集・削除、復元前自動バックアップ、端末間移行、iPhone実機確認。

## 受入基準
- 全7科目・全4事例。公式細目・過去問・参考教材の照合表と未対応一覧が存在。
- 初学者向けの原理説明、用語、具体例、図表、計算過程、誤答理由を実装。基礎と本試験相当の応用を区別。
- 新規の法令・政策・白書は年度・適用日・根拠を明記。
- 問題の重複、正答、計算、選択肢、配点、リンクを検証。
- 学習記録の再読み込み・更新時移行・不正バックアップ拒否・科目合格期限・オフライン・モバイルを試験。
- 2027/2028年度は公式案内が発表されるまでは暫定。教材量だけで合格水準を主張しない。
